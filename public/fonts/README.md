# Bundled fonts

Official Google Fonts Latin variable web fonts, obtained 2026-10-06. These are unmodified Google Fonts WOFF2 releases; each font includes its SIL Open Font License beside the binary.

The fonts are served by this app so typography does not depend on a browser request to Google Fonts. Characters outside these Latin subsets use the declared system fallback.
